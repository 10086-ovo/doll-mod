# 人偶模组（Doll Mod）

一个把人偶当作**可消耗工具**来用的 Minecraft 模组：用刷怪蛋召唤属于你的、可自定义名字的人偶，给它装备武器与盔甲，再用 8 种行为模式指挥它干活。人偶是消耗品——死了会连配置一起丢失，所以放心派它去危险环境、成群流水线作业。

> 依赖 Fabric API，目标版本 Minecraft 26.2（Java 25）。

## 安装方法

1. 安装 [Fabric Loader](https://fabricmc.net/use/) 与 [Fabric API](https://modrinth.com/mod/fabric-api)（版本需匹配 Minecraft 26.2）。
2. 下载本模组的 jar 文件，放入 `.minecraft/mods` 文件夹。
3. 启动游戏，创造模式物品栏中会出现"人偶"标签页。

## 快速上手

1. **合成 S1 蛋**：上下左右四个工作台 + 中间箱子 → S1 人偶刷怪蛋。
2. **铁砧赐名**：只有命名过的蛋才能召唤人偶（命名后蛋带附魔光效）。用石砧或原版铁砧均可。
3. **召唤/召回**：右键地面召唤；已绑定的蛋再右键地面把人偶传送到身边（支持跨维度、区块未加载自动等待加载）。
4. **升级不丢东西**：回收人偶后把蛋放工作台中间围升级材料升级，蛋的名字、物品栏（含护甲/副手）、作业区与盾构机配置会原样带到新蛋上，再召唤无需重新赐名、装备物品全部保留。注意蛋必须处于"未绑定"状态（回收后或从未召唤过）才能升级。
   - S1 → S2：围一圈铜锭
   - S2 → S3：十字铁锭 + 四角铜锭
   - S3 → S4：十字金锭 + 四角铁锭
   - S4 → S5：上下钻石 + 左右金锭 + 四角铁锭
5. **背包**：右键人偶打开 45 格专属背包（装饰/护甲/副手/存储/快捷栏），左侧实时显示血量。
6. **模式**：背包右侧 9 个按钮切换 8 种行为模式 + 跟随开关；也可以用**人偶遥控器**（`doll_panel`，铁锭-红石-铁锭竖排合成）右键任意位置打开控制面板，远程查看/切换所有已召唤人偶。
7. **指挥棒**（`doll_baton`，三根木棍对角合成）：
   - **作业模式**（砍树/耕种/挖矿）：右键人偶选中 → 右键方块两点划定**作业区**；挖矿模式下右键两个竖方块设定**盾构机入口**，沿点击面反方向掘进 1×2 隧道。
   - **战斗模式**（近战/射手）：右键人偶进入**目标选择模式** → 右键任意生物指定为攻击目标，人偶立即追杀；右键地面取消选择。幽匿人偶在非作业模式下均可指定。
   - 潜行右键人偶清除作业区/隧道/强制目标；作业区单边上限 64 格。

## 8 种行为模式

| 模式 | 行为 |
|------|------|
| 近战 | 主动攻击主人攻击的目标与附近敌对生物（需快捷栏放剑/斧等武器） |
| 射手 | 拉弓/弩射击，自动预判目标移动、追踪修正（需弓/弩 + 箭）；末影人偶持末影斧时自动投掷 |
| 耕种 | 锄地、播种、收获、灌水（需锄头/种子/水桶） |
| 喂食 | 贴身跟随主人，饥饿/低血时喂食 |
| 砍树 | 找真树（原木连通体 + 邻接树叶判定），连锁砍完整棵树（需斧头） |
| 挖矿 | BFS 扫描矿石，价值评分选目标，连锁挖同族矿脉（需镐子） |
| 插火把 | 寻找方块光与天空光都低的位置补光（需火把） |
| 钓鱼 | 找水域抛竿、等咬钩、按原版战利品表收鱼（需钓鱼竿） |

## 人偶等级（五阶阶梯式成长）

| 阶段 | 生命值 | 常驻效果 |
|------|--------|----------|
| S1 | 20 | 无 |
| S2 | 40 | 生命恢复 I |
| S3 | 60 | 生命恢复 II |
| S4 | 80 | 生命恢复 III + 抗性提升 I |
| S5 | 100 | 生命恢复 IV + 抗性提升 II |

工具材质等级（木/石/铁/钻石/下界合金）决定人偶能挖/砍动什么方块。

## 特殊人偶

七种特殊天赋人偶独立于 S1–S5 体系。特殊变体统一为 120 血 + 恢复 IV + 抗性 II（仅下界/海洋额外有抗火）；幽匿人偶为高难度强化版（200 血 + 恢复 VI + 抗性 IV + 抗火 + 满击退抗性）；向导人偶为功能型（120 血 + 恢复 IV + 抗性 II，不可升级，无战斗能力）。各变体详细数值与机制见 [docs/GAMEPLAY.md](docs/GAMEPLAY.md)。

### 幽匿人偶（高难度内容）

远古城市专属的高风险、高回报内容。**手持回响碎片右键幽匿灵龛**召唤**野生幽匿人偶**（见下），击败后有概率掉落幽匿人偶头颅（基础 60%，随抢夺附魔提高），用 8 个幽匿方块围住头颅合成幽匿人偶蛋。驯服形态与普通人偶玩法完全一致，天赋为**音波攻击**（蓄力 1.5 秒发射音波，30 点伤害 + 拉扯 + 缓慢 V）和**掠夺者**（击杀经验 ×3 + 攻击自带抢夺 III）。

### 野生幽匿人偶（BOSS）

独立于驯服人偶体系的**敌对 BOSS**（注册名 `wild_warden_doll`），由幽匿灵龛召唤。300 血 / 10 攻击 / 移动速度仿监守者 / 满抗击退 / 免疫火焰 / 弱再生 I。出场时从灵龛中丝滑上升 2 格并降落的动画。战斗机制：固定监守者速度追击，超出近战范围后蓄力发射**音波**（6 点穿甲伤害 + 拉扯，7 秒冷却，限 32 格）。被攻击后反击，创造/旁观模式不锁定。每个灵龛在上一个召唤的野生幽匿人偶死亡前不能再次召唤。

### 苍白人偶

苍白花园主题人偶。在苍白花园找到嘎枝之心（苍白橡树中 10% 概率生成）→ 破坏得树脂块 → 熔炉烧成树脂砖 → 4 个树脂砖合成头颅 → 8 苍白橡木原木围头颅合成蛋。天赋为**恐惧光环**（16 格内敌对生物失去索敌与攻击 AI，史莱姆等接触伤害单位被冻结）、**67% 易伤**（光环内生物受伤 ×1.67）和**献祭**（玩家致命时以命相抵，挡下死亡并 +100 临时生命）。

### 下界人偶

火焰主题人偶。4 个石英块合成头颅 → 8 个下界岩围头颅合成蛋。天赋为**烈焰弹**（自动发射凋灵骷髅头颅弹，20 点伤害 + 点燃）、**凋零免疫**、**灵魂沙免疫**、**下界生物安抚光环**（16 格内下界生物不会攻击人偶和主人）和**灼烧光环**（16 格内主人持续获得抗火）。

### 末影人偶

龙息主题人偶。4 个紫珀块合成头颅 → 8 个末影石围头颅合成蛋。天赋为**龙息喷吐**（发射龙息云，持续伤害）、**瞬移处决**（目标低于 25% 血时瞬移斩杀，60 秒冷却）、**闪避**（受击时近战 67% / 投射 100% 概率免伤并瞬移躲避）和**末影斧投掷**（远程模式下持有末影斧时自动投掷，斩杀线提升至 55%）。

### 海洋人偶

水下主题人偶。4 个海晶石合成头颅 → 8 个海带围头颅合成蛋。天赋为**海洋生物安抚光环**、**水下适应**（不溺水、水下全速）、**高效钓鱼**（标准战利品表，咬钩更快、收杆双倍产物）、**守卫者激光**（蓄力发射 hitscan 激光，20 点魔法伤害）和**主人增益光环**（范围内主人获得水下呼吸 + 水下速掘）。

### 森林人偶

自然守护主题人偶。4 个苔石合成头颅 → 8 个橡木原木围头颅合成蛋。天赋为**藤蔓缠绕**（16 格内所有敌对生物减速 + 中毒）、**友善生物吸引**（吸引未驯服动物）、**主人回血光环**、**近身威胁高亮**（16 格内敌对生物发光描边）和**副手荆棘盾反伤**（副手持荆棘盾牌时 100% 反弹所受伤害）。

### 向导人偶

探索导向的功能型人偶，相当于随身携带的 `/locate`。4 个指南针合成头颅 → 8 张纸围头颅合成蛋。天赋为**引导光环**（主人获得速度 II + 跳跃 II + 免疫凋零，半径 16 格，仅主人受益）。打开其背包后点击左侧**搜索**按钮进入**目标搜索界面**，可按 结构 / 群系 / 村庄 三个标签分类搜索：**13 种结构**、**14 种群系**、**5 种村庄**，以玩家当前位置为中心**100 区块（1600 格）半径**内搜索，结果展示坐标与距离，支持**刷新**重搜与**标记为已探索**（跨会话持久）。

## 其他物品

### 末影斧

近战 + 投掷混合武器（`ender_axe`），耐久 2031。合成配方：金锭 + 末影珍珠 + 木棍。

- **近战**：9 点伤害（对标下界合金斧），可剥皮原木。
- **投掷**：长按右键蓄力，松手扔出投掷末影斧，带**忠诚**附魔可飞回（玩家和人偶都能接）。
- **玩家专属**：主手/副手持有时 **80% 闪避**（只对攻击类伤害生效，环境伤害正常结算）；对 30% 血以下怪物**斩杀**。
- **末影人偶持有时**：斩杀线提升至 55%。

### 地狱剑

下界主题近战武器（`nether_sword`），数值对标下界合金剑。合成配方：两根烈焰棒 + 木棍。玩家专属能力（人偶不触发，人偶另有自身常驻抗火逻辑）：

- **持有抗火**：主手/副手持有时持续获得抗火，放下后 2 秒内消退。
- **生命上限 +10**：手持时生命上限由 20 提至 30，放下回落。
- **点燃**：攻击命中点燃目标 4 秒（与原版火焰附加 I 一致，可叠加）。
- **守护飞剑**：长按右键蓄力 1 秒，召唤一把**飞行地狱剑**（`nether_flying_sword`），自动攻击 16 格半径内最近的敌对生物，命中 4 点伤害 + 点燃 8 秒；同时仅一把，重复召唤顶替旧剑。下界人偶持剑时同样可召唤。

### 苍白弓

苍白花园主题远程武器（`pale_bow`），继承原版弓全部机制（蓄力射箭、附魔、耐久消耗），耐久 1536（钻石级，原版弓 384 的四倍）。合成配方：树脂砖 + 线。**特殊效果**：箭矢命中生物时施加**易伤**（受伤 +15%，持续 5 秒），玩家和人偶射箭均生效；与苍白人偶恐惧光环的 ×1.67 乘算叠加，总计 ×1.92。

### 海洋套装

水下主题盔甲套装（`sea_helmet` / `sea_chestplate` / `sea_leggings` / `sea_boots`），数值对标钻石套。无合成配方，作为**埋藏宝藏**的额外战利品掉落。

### 石砧

便宜的铁砧替代品（`rock_anvil`），与原版铁砧行为一致（可赐名、可修复），但总耐久更少。三个损伤状态（完好/微裂/大裂）为独立方块，会下落、落地时降级；每个阶段可用 3 次，总共 9 次，每用完 3 次自动切换到下一损伤状态。合成配方：3 圆石 + 4 圆石台阶。

### 荆棘盾牌

森林主题防御装备（`thorns_shield`），耐久 672（铁剑的 2 倍），可附魔，可通过铁砧修复。基础格挡行为与原版盾牌一致，但对"绕过盾牌"的伤害类型（魔法、火焰、窒息等 `bypasses_shield`）不生效。

- **玩家格挡（举盾）**：右键举盾，完全免疫普通伤害，命中消耗耐久；格挡成功的瞬间对 **3 格内**攻击者反弹 **2 点荆棘伤害**（无视护甲、无视对方盾牌、无递归），并播放原版盾牌格挡音效。
- **森林人偶副手佩戴**：作为被动饰品，不主动格挡，但受击时向攻击者反弹 **100% 荆棘伤害**并播放格挡音效；同时激活森林人偶副手饰品增强逻辑。
- **合成配方**：

  ```
  原木 铁块 原木
  原木 原木 原木
   ·   原木  ·
  ```

  `L` = 任意原木（`#minecraft:logs`，含所有去皮/木质变体），`I` = 铁块（`iron_block`）。产出 1 个荆棘盾牌。

### 人偶指南书

内置玩法指南书（`guide_book`），**首次进入世界时自动发放**到背包。右键打开指南界面，分章节介绍人偶玩法、物品与特殊变体（数据位于 `assets/doll-mod/patchouli_books/guide_book/`）。

## 配置

本模组提供外置配置：`config/dollmod/doll.json`（JSON，首启自动生成）。包含索敌 / 觅途 / 跟随 / 各模式阈值时限开关等全部调参项，服主与玩家可改而勿须重编。使用命令 **`/dollmod reload`**（OP 权限）重新载入并即时生效。

## 已知问题

- **首帧渲染加载期卡顿**：日志中可能显示 `客户端 tick 间隔 1801ms` 等提示，发生在游戏开启前的加载阶段（首次渲染人偶时资源惰性加载 + JVM 热身）。进入游戏后完全流畅，玩家无感，属正常现象。
- **无已知运行时崩溃**。
